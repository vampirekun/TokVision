# Security Policy

## Supported Versions

TokVision is currently supported through the latest code on the `main` branch and active pull requests that target it.

## Reporting a Vulnerability

Please use GitHub's private vulnerability reporting flow for this repository to disclose security issues. Do not open a public issue or pull request for an unpatched vulnerability.

Include the affected commit or version, impact, reproduction steps, and any suggested mitigations. Maintainers will acknowledge reports within 3 business days, assess severity, and coordinate a fix before public disclosure.

Once a fix is available, the response path is:

1. Prepare and review the patch privately.
2. Merge the fix and publish the remediation in the repository history and release notes.
3. Disclose the issue publicly only after a fix or mitigation is available.
