Política de Privacidad de TokVision

Última actualización: agosto de 2026

TokVision es una aplicación cliente para Android TV / Google TV que se conecta a tu propia cuenta de TikTok mediante el mecanismo oficial de autenticación de TikTok for Developers (OAuth 2.0 + PKCE). Esta página explica qué datos procesa la aplicación, dónde se almacenan y con quién se comparten.

1. Qué datos accede TokVision

DatoOrigenUso
open_id, nombre, avatar, biografíaTikTok Display API (/v2/user/info/)Mostrar tu perfil dentro de la app
Lista de tus propios vídeos publicadosTikTok Display API (/v2/video/list/, /v2/video/query/)Mostrar y reproducir tus vídeos
access_token / refresh_tokenTikTok Login Kit (OAuth)Mantener tu sesión iniciada
Favoritos e historial de reproducciónGenerado localmente por tu uso de la appRecordar qué vídeos marcaste o viste

TokVision no solicita ni accede a tu lista de seguidores/seguidos, mensajes privados, ni contenido de otros usuarios de TikTok — esos datos no están disponibles a través de las APIs oficiales que usa la aplicación.

2. Dónde se almacenan tus datos

Todo se almacena únicamente en tu propio dispositivo Android TV:

  • Los tokens de sesión (access/refresh token) se guardan cifrados mediante EncryptedSharedPreferences, respaldados por el Android Keystore del dispositivo (cifrado AES-256).
  • Los favoritos, el historial y los ajustes se guardan en una base de datos local del dispositivo.
  • TokVision no tiene servidor propio ni backend: no existe ninguna base de datos remota controlada por los desarrolladores de TokVision donde se almacenen tus datos o tokens.

3. Con quién se comparten tus datos

TokVision solo se comunica directamente con los servidores oficiales de TikTok (tiktok.com y open.tiktokapis.com) para autenticarte y obtener tu perfil/vídeos. TokVision no envía tus datos a ningún otro tercero, no incluye publicidad ni analítica de terceros, y no vende ni comparte tus datos con fines comerciales.

4. Cómo eliminar tus datos

Puedes cerrar sesión desde Ajustes → Cuenta → Cerrar sesión dentro de la app en cualquier momento, lo que elimina inmediatamente los tokens almacenados en el dispositivo. Desinstalar la aplicación elimina también el historial y los favoritos locales. Para revocar el acceso de TokVision a tu cuenta de TikTok desde el lado de TikTok, ve a la configuración de tu cuenta de TikTok → Seguridad y privacidad → Aplicaciones y sitios web conectados.

5. Menores de edad

TokVision no está dirigido a menores de edad y no recopila deliberadamente información de menores. El uso de la app requiere iniciar sesión con una cuenta de TikTok existente, sujeta a los propios requisitos de edad de TikTok.

6. Cambios a esta política

Si esta política cambia, la versión actualizada se publicará en esta misma URL.

7. Contacto

Este proyecto es de código abierto. Consulta el repositorio en github.com/vampirekun/TokVision para reportar problemas o dudas sobre privacidad.
