Política de Privacidad de TokVision

Última actualización: 26 de octubre de 2026

TokVision es una aplicación cliente para Android TV / Google TV que se conecta a tu propia cuenta de TikTok mediante el mecanismo oficial de autenticación de TikTok for Developers (OAuth 2.0 + PKCE). Esta página explica qué datos procesa la aplicación, dónde se almacenan y con quién se comparten.

1. Qué datos procesa la versión actual

DatoOrigenUso en la versión actual
open_idRespuesta OAuth de TikTok Login KitIdentificar la cuenta conectada; no se consulta el perfil.
access_token, refresh_token y expiraciónEndpoint OAuth de TikTok Login KitMantener y renovar la sesión.
state y code_verifier de PKCEGenerados para cada intento de inicio de sesiónValidar el retorno OAuth; se mantienen en memoria y se descartan al completar o cancelar el flujo.
Nombre, avatar, biografía y vídeos propiosNo se obtienen en la versión actual; los endpoints Display API aún no están implementados.No se muestran ni almacenan. El scope video.list no se solicita.
Favoritos e historial de reproducciónFuncionalidad aún no implementadaNo se almacenan; no existe todavía una base de datos local para ellos.

La versión actual solicita únicamente el scope user.info.basic para el flujo de identidad OAuth. No llama a /v2/user/info/, /v2/video/list/ ni /v2/video/query/; el scope video.list se añadirá solo cuando la función de vídeos propios esté implementada. TokVision tampoco solicita seguidores/seguidos, mensajes privados ni contenido de otros usuarios.

2. Dónde se almacenan tus datos

La información que TokVision persiste se guarda en tu propio dispositivo Android TV. El flujo de autenticación sí intercambia solicitudes y respuestas con los servidores oficiales de TikTok descritos en la sección 3; TokVision no almacena tu contraseña de TikTok.

  • open_id, los tokens de sesión y su expiración se guardan cifrados mediante EncryptedSharedPreferences, respaldados por Android Keystore.
  • El estado PKCE (state y code_verifier) solo vive en memoria durante el intento de login; no se persiste.
  • Los favoritos e historial aún no existen como funciones y no se guardan. Los valores de calidad/reproducción que aparecen en Ajustes son placeholders, no preferencias persistidas.
  • TokVision no tiene servidor propio ni backend; no existe una base de datos remota controlada por sus desarrolladores.

3. Con quién se comparten tus datos

El cliente HTTP de TokVision usa el endpoint OAuth de open.tiktokapis.com para intercambiar o renovar tokens. El WebView abre la página oficial de autorización de tiktok.com, que puede cargar los recursos propios de TikTok. La versión actual no llama a la Display API ni obtiene perfiles o vídeos. TokVision no incluye publicidad ni analítica de terceros, no tiene backend propio y no vende ni comparte tus datos con fines comerciales.

4. Cómo eliminar tus datos

Puedes cerrar sesión desde Ajustes → Cuenta → Cerrar sesión; esto elimina los tokens y el open_id guardados localmente. El cierre de sesión no revoca por sí solo el permiso en los servidores de TikTok. Para revocarlo, abre la configuración de tu cuenta de TikTok → Seguridad y privacidad → Aplicaciones y sitios web conectados. Desinstalar TokVision elimina los datos locales de la aplicación. Como favoritos e historial aún no están implementados, esta versión no tiene esos registros que borrar.

5. Menores de edad

TokVision no está dirigido a menores de edad y no recopila deliberadamente información de menores. El uso de la app requiere iniciar sesión con una cuenta de TikTok existente, sujeta a los propios requisitos de edad de TikTok.

6. Cambios a esta política

Si esta política cambia, la versión actualizada se publicará en esta misma URL.

7. Contacto

Este proyecto es de código abierto. Consulta el repositorio en github.com/vampirekun/TokVision para reportar problemas o dudas sobre privacidad.
