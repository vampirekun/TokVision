TokVision

TokVision es un cliente ligero y no oficial de TikTok, diseñado específicamente para Android TV y Google TV, controlado por completo con el mando a distancia (D-pad).

¿Qué hace?

  • Inicia sesión con tu propia cuenta de TikTok mediante el flujo oficial OAuth de TikTok for Developers.
  • Muestra tu perfil y los vídeos que tú mismo has publicado, usando la Display API oficial de TikTok.
  • Reproduce vídeo de forma fluida y eficiente, optimizado para hardware de TV.
  • Guarda favoritos e historial localmente en tu dispositivo.

¿Qué NO hace?

No muestra un feed algorítmico de otros usuarios, no permite buscar contenido de terceros, ni dar like/comentar/seguir cuentas ajenas — esas funciones no están disponibles a través de las APIs públicas de TikTok. Ver el detalle completo en el repositorio.
