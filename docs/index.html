TokVision

Cliente independiente y ligero para Android TV y Google TV. Su interfaz está diseñada para navegar con el control remoto; utiliza el flujo oficial OAuth de TikTok for Developers para la autenticación.

Estado de desarrollo — 9 de noviembre de 2026

El código de OAuth Login/Logout existe, pero TokVision todavía no está listo para distribución pública. El intercambio de tokens de la implementación de desarrollo incorpora el client secret en el APK. No distribuyas builds que contengan un secreto real. Antes de habilitar login para usuarios finales se requiere un backend/token broker HTTPS; ese servicio aún no existe.

Qué está implementado

  • Interfaz para Android TV / Google TV con navegación D-pad.
  • Flujo de autenticación OAuth 2.0 + PKCE mediante WebView.
  • Inicio y cierre de sesión en el alcance de desarrollo.
  • Almacenamiento local cifrado de tokens e identificador de cuenta.

Qué todavía no está disponible

  • Perfil propio y consulta de vídeos mediante Display API.
  • Reproducción de vídeos.
  • Favoritos e historial.
  • Feed For You/Following, búsqueda, likes, comentarios o follows de terceros.

TokVision no utiliza scraping ni endpoints privados para simular funciones que las APIs públicas no ofrecen.

Instalación y uso

La guía de usuario contiene requisitos, instalación de QA desde el código fuente, primer login, CAPTCHA, solución de problemas, privacidad y política de versiones.
