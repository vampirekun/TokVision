1. Estado y alcance real

TokVision es un cliente ligero para Android TV y Google TV, diseñado para navegación con D-pad. No es una aplicación oficial de TikTok ni está afiliada, patrocinada o respaldada por TikTok o ByteDance.

Implementado en código

Inicio y cierre de sesión OAuth 2.0 + PKCE mediante WebView, más almacenamiento local cifrado de la sesión.

Pendiente

Backend/token broker HTTPS para mantener el client secret y los refresh tokens fuera del APK. Sin él, el login no debe habilitarse para distribución pública.

No implementado

Display API, perfil, vídeos propios, reproducción, favoritos e historial.

Funciones que no están disponibles

  • Feeds “For You” o “Following”.
  • Búsqueda de usuarios, vídeos o hashtags.
  • Reproducción de vídeos de terceros.
  • Likes, comentarios o follows sobre contenido ajeno.
  • Favoritos e historial local.

Estas limitaciones son deliberadas: TokVision no utiliza scraping, endpoints privados ni ingeniería inversa para simular funciones que las APIs públicas de TikTok no ofrecen.

Consulta las limitaciones conocidas en el repositorio para el detalle técnico.

2. Requisitos y dispositivos

  • Plataforma objetivo: Android TV o Google TV.
  • Android mínimo declarado: Android 6.0 (API 23).
  • Entrada: control remoto con D-pad; un mouse USB/Bluetooth puede ser necesario si TikTok presenta un CAPTCHA de arrastre.
  • Conectividad: internet durante el inicio de sesión y las solicitudes OAuth.
  • Orientación: paisaje (landscape).

La aplicación declara el launcher de Android TV y no exige pantalla táctil. Eso no garantiza compatibilidad con todos los televisores, mandos, versiones modificadas de Android o fabricantes. La aceptación en cada dispositivo debe probarse físicamente.

La aplicación está diseñada para TV.

No se ofrece compatibilidad oficial con teléfonos o tablets Android, aunque algunos dispositivos puedan permitir instalar el APK.

3. Instalación de QA desde el código fuente

No hay un canal estable de APK público confirmado. Esta sección describe un procedimiento de desarrollo/QA, no una instalación de producción para usuarios finales. Usa únicamente código y artefactos verificables del repositorio.

Herramientas de desarrollo

  • JDK 17.
  • Android SDK y herramientas de plataforma (ADB).
  • Windows PowerShell para los comandos de ejemplo siguientes; adapta las rutas si usas otro sistema operativo.

Compilar un APK de depuración

git clone https://github.com/vampirekun/TokVision.git
cd TokVision
.\gradlew.bat assembleDebug

El APK de depuración se genera en app\build\outputs\apk\debug\app-debug.apk. El proyecto puede compilar sin credenciales de TikTok; eso no significa que el login vaya a completar el intercambio OAuth.

Instalar en la TV mediante ADB

  1. En la TV, abre Ajustes → Preferencias del dispositivo → Acerca de y pulsa siete veces sobre “Compilación” para habilitar Opciones de desarrollador. Los nombres pueden variar según el fabricante.
  2. En Opciones de desarrollador, habilita la depuración USB o de red.
  3. Obtén la IP local de la TV y conéctate desde el PC:
adb connect <IP_DE_LA_TV>:5555
adb install -r app\build\outputs\apk\debug\app-debug.apk

Autoriza la conexión en la pantalla de la TV si Android lo solicita. Abre TokVision desde la fila de aplicaciones del launcher.

No compartas el APK de depuración.

Los valores incorporados en un APK pueden extraerse. Nunca empaquetes ni distribuyas un client secret real. La protección de release está en revisión y el backend/token broker todavía no existe.

4. Primer inicio de sesión

  1. Abre Ajustes → Cuenta → Iniciar sesión.
  2. TokVision abre la página oficial de autorización de TikTok dentro de un WebView.
  3. Introduce tus credenciales directamente en la página de TikTok. TokVision no necesita ni almacena tu contraseña.
  4. Completa el método de verificación que TikTok solicite, por ejemplo código SMS o autenticador, si corresponde.
  5. Si TikTok muestra un CAPTCHA, resuélvelo manualmente. Consulta la sección siguiente.
  6. Al completar el consentimiento, TikTok devuelve el flujo OAuth a la aplicación.

La aplicación solicita actualmente el scope user.info.basic para el flujo de identidad. No consulta todavía la Display API ni obtiene perfil o vídeos. La presencia de una sesión autenticada no significa que esas pantallas estén implementadas.

Para pruebas de desarrollo, la aplicación de TikTok debe estar configurada correctamente en TikTok for Developers y la cuenta debe cumplir las restricciones del entorno Sandbox o del proceso de revisión que corresponda. La URI de redirección debe coincidir exactamente con la registrada.

La configuración técnica de desarrollador está descrita en BUILD.md. No uses credenciales de producción en APKs compartidos.

5. CAPTCHA y control remoto

TikTok puede mostrar un CAPTCHA de arrastre. Un D-pad normalmente no produce el gesto continuo que exige ese control.

  • Si aparece, conecta temporalmente un mouse USB o Bluetooth y resuelve el desafío tú mismo.
  • Si no puedes completarlo, cancela y vuelve a intentarlo más tarde, sin repetir intentos de forma compulsiva.
  • No automatices el CAPTCHA con JavaScript, macros o movimientos sintéticos.
  • Evita mantener la depuración remota de WebView activa durante un inicio de sesión real; puede interferir con las señales de confianza que evalúa TikTok.
El CAPTCHA no es un defecto que TokVision deba esquivar.

La aplicación no debe resolverlo por el usuario ni intentar ocultar el comportamiento de automatización. Si persiste, detén los reintentos y utiliza los canales de soporte de TikTok.

6. Solución de problemas

SíntomaQué revisar
invalid_client o error inmediato de OAuthVerifica que la app de TikTok esté configurada, que el client key corresponda al entorno y que la redirect URI coincida exactamente. Un build sin credenciales válidas no puede completar el intercambio.
La cuenta no puede entrar en SandboxComprueba que el usuario esté añadido como tester y que la app/entorno tengan el estado correcto en TikTok for Developers.
El CAPTCHA pide arrastrar una piezaUsa un mouse USB/Bluetooth. No intentes resolverlo con automatización ni depuración remota.
TokVision no aparece en el launcherConfirma que el dispositivo sea Android TV/Google TV y que la instalación ADB haya terminado correctamente. La app declara la categoría LEANBACK_LAUNCHER.
El login termina, pero no aparecen vídeos o perfilEs el alcance actual: Display API, perfil y vídeos propios todavía no están implementados.
Después de cerrar sesión TikTok vuelve a reconocer la cuentaEl cierre de sesión elimina la sesión local de TokVision, pero las cookies del WebView pueden persistir. Para revocar el permiso, hazlo desde la cuenta de TikTok; para borrar cookies locales, limpia los datos de la app en Android.
El APK no se instalaComprueba la versión de Android, la arquitectura del dispositivo, el espacio disponible y que el archivo no esté incompleto. No desactives verificaciones de seguridad para forzar la instalación.

Si el problema continúa, abre un reporte en GitHub Issues. Incluye modelo de TV, versión de Android, versión/build de TokVision y pasos para reproducirlo. No adjuntes contraseñas, tokens, cookies, client secrets ni capturas que los muestren.

7. Privacidad y seguridad

  • La contraseña se introduce en la página oficial de TikTok; TokVision no la almacena.
  • Los tokens OAuth y el identificador de cuenta se guardan localmente mediante almacenamiento cifrado respaldado por Android Keystore.
  • El estado PKCE se mantiene en memoria durante el intento de autenticación.
  • El manifiesto desactiva el backup de datos de la aplicación.
  • TokVision no tiene actualmente un backend propio ni una base de datos remota de usuarios.
  • Las cookies y el almacenamiento web de TikTok pueden persistir en el WebView después del logout.

Cerrar sesión no equivale a revocar el permiso

Usa Ajustes → Cuenta → Cerrar sesión para eliminar la sesión local de TokVision. Para revocar el acceso concedido a la aplicación, entra a la configuración de seguridad de tu cuenta de TikTok y elimina TokVision de las aplicaciones conectadas. Para borrar también los datos locales del WebView, limpia los datos de TokVision desde los ajustes de Android.

Bloqueo de distribución

La implementación de desarrollo actual realiza el intercambio OAuth desde Android e incorpora el client secret en el APK. Un secreto empaquetado en una aplicación cliente puede extraerse; PKCE no cambia ese hecho. No distribuyas APKs que contengan un client secret real. Antes de habilitar login para usuarios finales se requiere un backend/token broker HTTPS que realice el intercambio y mantenga el client secret y los refresh tokens del lado servidor. Ese servicio todavía no está implementado.

Lee la Política de Privacidad y los Términos de Servicio para el detalle legal y de tratamiento de datos.

8. Versiones y distribución

La versión documentada corresponde a 0.2.0-auth y es un estado de desarrollo, no una promesa de compatibilidad o soporte estable.

  • No hay todavía una versión estable aprobada para distribución pública.
  • El canal oficial de distribución debe anunciarse junto con el proceso de firma y verificación de artefactos.
  • No instales APKs republicados por terceros ni builds cuya procedencia y checksum no puedas verificar.
  • Una compilación exitosa o un APK generado por CI no significa que el login real, la revisión de TikTok, la firma o la distribución estén aprobados.

Cuando exista un release público, utiliza únicamente el artefacto y las instrucciones publicados desde el repositorio oficial, junto con sus notas de versión y checksum.

9. Preguntas frecuentes

¿TokVision es una aplicación oficial de TikTok?

No. Es un proyecto independiente que utiliza el flujo oficial de autenticación de TikTok for Developers.

¿Puedo ver el feed For You o Following?

No. Las APIs públicas de consumo general no ofrecen esos feeds a TokVision. El proyecto no utiliza scraping ni endpoints privados.

¿Puedo ver los vídeos de mi propia cuenta?

Todavía no. La integración de Display API y la consulta de vídeos propios están pendientes.

¿Necesito tener instalada la aplicación móvil de TikTok?

No para el flujo WebView descrito aquí. La autorización se abre en la propia TV mediante el navegador integrado de Android.

¿Puedo usar mi cuenta principal?

TokVision sigue en pre-release y el flujo de intercambio OAuth no tiene aún el backend requerido para una distribución pública segura. Limita las pruebas a cuentas y entornos de desarrollo apropiados; no introduzcas credenciales en APKs de procedencia dudosa.

¿Cuándo estará disponible la versión pública?

No hay una fecha de lanzamiento confirmada. Primero deben completarse el token broker, la revisión de seguridad, la aceptación en dispositivos reales y la estrategia de distribución.

TokVision es un proyecto independiente. TikTok y sus marcas pertenecen a sus respectivos titulares.
